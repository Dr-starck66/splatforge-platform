Deux photos. Un nuage 3D. Un vrai fichier exporté.

Chargez deux photos stéréo rectifiées du même objet, prises avec un petit déplacement horizontal. Le moteur analyse les correspondances de pixels, triangule les points 3D et exporte .ply et .splat directement dans votre navigateur. Version expérimentale : ce n’est pas COLMAP ni le pipeline 3DGS NVIDIA.

Les images restent sur votre appareil. Mode adapté aux paires stéréo déjà rectifiées, éclairage stable, même taille d’image. Les photos ordinaires non rectifiées peuvent donner des résultats médiocres.

02 · Modèle 3D interactif

Faites glisser pour pivoter, utilisez la molette ou pincez pour zoomer. Aucun modèle fictif n’est affiché avant un véritable calcul.

Portée du moteur. Reconstruction expérimentale avec correspondance stéréo locale (SAD), rejet des zones peu texturées, triangulation selon une caméra rectifiée et export des points. Les formats sont authentiques, mais la profondeur absolue nécessite une vraie calibration. Pour la reconstruction photographique multi-vues haute fidélité, utiliser le backend SplatForge + COLMAP.
